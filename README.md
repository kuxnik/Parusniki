# Парусники

Игра для Android про парусные корабли: открытое море, ветер и паруса, торговля, бои, драконы и аватары.

## Где поиграть

- **Android:** раздел [Releases](../../releases/latest) → скачайте `Parusniki.apk` и откройте на телефоне (разрешите установку из неизвестных источников). APK собирается автоматически при каждом изменении в `godot/`.
- **Браузер (любой телефон, включая iPhone):** https://kuxnik.github.io/Parusniki/ — полная версия-прототип: бои, порты, боссы, конструктор, погода. Старая 2D-версия: https://kuxnik.github.io/Parusniki/2d.html

## Структура

| Папка | Что это |
|---|---|
| `web/index.html` | Прототип в браузере (three.js), всё в одном файле: физика, бой, порты, боссы, конструктор, погода |
| `web/2d.html` | Первый 2D-прототип |
| `godot/` | Версия на Godot 4.3 для Android (идёт перенос) |
| `.github/workflows/android.yml` | Сборка и подпись APK, выпуск в Releases |
| `.github/workflows/pages.yml` | Публикация браузерной версии на GitHub Pages |

## Перенос на Godot

Готово (0.1): физика парусов и корпуса 1:1 с прототипом, острова и порты, океан, сутки, управление, след и брызги.

Дальше: бой → враги и ИИ → порты и торговля → корабли-существа → боссы и силы → конструктор → погода.

Подробнее — в [godot/README.md](godot/README.md).
