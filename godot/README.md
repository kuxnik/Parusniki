# Парусники — Godot 4.3, версия 0.1

Перенос ядра прототипа на движок Godot 4.3 (рендер GL Compatibility, подходит для большинства Android-телефонов).

## Что внутри
- `scripts/game_data.gd` — паруса фракций (крыло: подъёмная сила/сопротивление), типы парусов, глубины, волны, данные мира.
- `scripts/ship_sim.gd` — физика корабля 1:1 из прототипа: вымпельный ветер, корпус и волновое сопротивление, киль/шверт, крен и оверкиль, вёсла, мели.
- `scripts/ship_view.gd` — модель корабля: корпус, мачты, паруса с «пузом» и заполаскиванием, вымпел по ветру.
- `scripts/world.gd` — острова с пальмами, порты, океан (шейдер `shaders/ocean.gdshader`), небо со сменой суток, туман, ночные огни.
- `scripts/hud.gd` — руль и паруса (мультитач), роза ветров, сообщения, выбор корабля.
- `scripts/main.gd` — сборка сцены, ветер, камера, след и брызги.
- `world_data.json` — острова, порты и корабли из прототипа.

## Как открыть
Godot 4.3: «Импорт» → выбрать `project.godot`. На Android-планшете или телефоне можно в приложении Godot Editor.

## Сборка APK
Проект → Экспорт → Android. Для подписанного APK укажите в настройках редактора путь к Android SDK и debug.keystore.

## Дальше по плану
Бой и снаряды → враги и ИИ → порты, торговля, заказы → корабли-существа (драконы, аватары) → боссы и силы → конструктор → погода.
